# Spiekbrief Git en GitHub
## 1. Clone, commit, push en pull
Met clone kopieer je een project van GitHub naar je laptop.
Met commit sla je je aanpassingen op
Met push stuur je wat je hebt opgeslagen naar GitHub
Met pull haal je wat op GitHub staat naar je laptop

## 2. Een goed commitbericht
Een goed voorbeeld; "Spiekbrief: uitleg over Git toegevoegd".
Een slecht voorbeeld; "Iets toegevoegd".
De eerste is beter, omdat die duidelijk zegt wat je hebt veranderd.

## 3. Gitignore
Met gitignore zorg je ervoor dat Git bepaalde bestanden niet opslaat.
## 4. Pull
Met pull haal je de nieuwste aanpassingen van GitHub naar je laptop. Je gebruikt pull voordat je begint zodat je met de niewste versie werkt.

Ik had deel 2 van mijn spiekrief verwijderd. Met revert heb ik die deel er terug ingezet.
